# 🎮 遊戲企劃書："SLO-MO: 慢速極限" (The Incredibly Slow Survival)

這是一款專為瀏覽器設計的 HTML5 / WebGL 動作解謎遊戲。它融合了現代網頁遊戲的「硬核肌肉記憶」、「AI 創意合成」與「反向天梯」優勢，打造出極具迷因爆紅潛力的魔性作品。

---

## 💡 核心創意與反差
一般動作遊戲拼的是「快節奏與閃電反應」；本作反其道而行。**玩家控制的主角動作慢到令人髮指，但關卡內的陷阱與環境卻是正常速度（甚至極快）**。玩家無法依賴即時反應，必須完全依賴「精準預判」與「時間管理」來通關。

---

## 🕹️ 核心遊戲機制

### 1. 硬核平台動作 ✕ 物理預判
* **動作延遲機制**：玩家控制三趾樹懶。按下「向右鍵」後，角色需要經過 **0.8 秒** 的抬腿與重心轉移才會真正跨出第一步。
* **肌肉記憶與預判**：面對迎面而來的致命陷阱，看見危險才按閃躲一定會死。玩家必須提前 1 秒預判，完美計算動作的延遲時間。

### 2. 慢速超感官（Slow-Vision）
* **聲納預知模式**：按下空白鍵可啟動短暫的「絕對靜止」黑白聲納模式，畫面會勾勒出危險落石、電鋸的路徑軌跡線。
* **動態音效回饋**：當樹懶停下不動時，背景音樂會變得空靈、清晰，能聽清危險逼近的節奏；開始移動時風聲變大，考驗玩家對時間點的掌握。

### 3. 生態系創意合成
* **抓取與黏合**：樹懶強力的爪子在移動中可以沿途抓取植物或昆蟲，並將它們黏在背上。
* **自由調配 Buff**：
  * `樹懶` + `苔蘚` = **隱身（不會被胡蜂攻擊）**
  * `樹懶` + `蝸牛黏液` = **止滑（可在垂直岩壁上固定 5 秒不下滑）**
  * `樹懶` + `電鰻` = **超頻（打破慢速限制，瞬間暴衝 0.5 秒，隨後癱瘓 3 秒）**

### 4. 全球「最慢通關」反向天梯榜
* **反向競速（Anti-Speedrun）**：排行榜不比誰最快，而是比**「在活著通關的前提下，誰的移動步數最少、通關時間最慢」**。
* **迷因幽靈系統**：網頁端即時連線，玩家可以在畫面上看到其他玩家化身的「幽靈樹懶」，以極其緩慢的姿態在身邊集體蠕動。

## 🖥️ 網頁極簡操作說明
免下載安裝，點開網頁即可用以下按鍵進行極簡操作：

| 按鍵 | 動作指令 | 備註說明 |
| :--- | :--- | :--- |
| **`A` / `D` (或 ⬅️ / ➡️)** | 向左 / 向右移動 | 帶有 0.8 秒物理延遲，按住可蓄力跨大步。 |
| **`W` (或 ⬆️)** | 向上抓取 | 伸出爪子抓取上方的樹枝或固定物。 |
| **`Space` (空白鍵)** | 啟動超感官預知 | 進入靜止黑白畫面，看清陷阱軌跡。 |
| **`1` / `2` / `3`** | 使用生態道具 | 觸發背上合成的各種環境 Buff。 |

---

## 🎨 視覺與音效風格
* **畫面視覺**：採用現代 WebGL 驅動的精緻體素風（Voxel Art），流暢度高、載入速度快（不超過 2 秒）。樹懶的毛髮會隨著關卡推進長出真正的綠色苔蘚。
* **魔性音效**：當樹懶以極慢的速度與致命電鋸擦身而過時，會發出非常慢速、低沉的「呃……啊……」驚嘆聲，極具迷因傳播效果。
